opensw: getting started

A math editor rebuilt after Scientific Word 5.5.
The screen, menus and shortcuts follow 5.5 as closely as possible; 5.5 .tex files and 6.x .sci files both open.
The full description of every menu: Help > Full manual.

Opening and saving

  • File > Open: .sci (6.x) and .tex (5.x) both work.
  • 5.x .tex comes first: an opened .tex is saved back to the same file, Chinese in Big5, and 5.5 can open it. New documents are saved as .tex.
  • To save as 6.x .sci, use File > Save as .sci.
  • The desktop app keeps the old file as .bak before saving.

Typing and formulas

  • Ctrl+M or typing $ starts a formula; Ctrl+D makes a displayed formula.
  • Fraction Ctrl+F, radical Ctrl+R, superscript Ctrl+H, subscript Ctrl+L. Press F1 for the full list of shortcuts.
  • To edit a formula's TeX directly, put the cursor in it and press Ctrl+F5.

Compute

  • Put the cursor in a formula and press Ctrl+E to compute; the result follows the formula.
  • The Compute menu simplifies, expands, factors, solves equations, does calculus, matrices and statistics, using SymPy.
  • The first computation loads the engine; wait a few seconds. The web demo may not compute; use the desktop app.

Tables, pictures, footnotes

  • Insert > Table. In a table, Tab goes to the next cell; Ctrl+F5 changes alignment and lines.
  • File > Import picture. Select a picture and press Ctrl+F5 to change its size and caption.
  • 5.5 plots are drawn again from their own settings.
  • Insert > Note adds a footnote or a margin note. Click the small number to edit it.

Typesetting and exporting

  • Ctrl+P typesets a PDF (desktop app).
  • Export LaTeX, HTML and Markdown (for AI) are in the File menu.

Commands it does not know

5.x commands that are not recognised are kept as they are in grey TeX fields. Saving and exporting keep them, and typesetting uses them.

Letting AI help

The desktop app has MCP: AI such as Claude can read, change, compute and typeset the document directly.
